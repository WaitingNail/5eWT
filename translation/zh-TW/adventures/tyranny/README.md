# HotDQ／RoT 翻譯資料

沿用使用者已採用的全站翻譯方式：既有網站名稱優先，未有對照者使用標示為`project-proposed`的暫定名稱，後續依回饋修訂。翻譯與全站驗證已完成，使用者已明確確認發布至現有公開網站；發布授權與驗證紀錄見校對報告。

- `terminology.json`：跨書人名、地名、派系與變體。
- `site-terminology.csv`：採用的既有網站名稱及來源檔案。
- `chapter-labels.csv`：全部具名標題與原英文名稱。
- `block-classification.csv`：逐文字欄位的自動內容類型與分類信心值。
- `text-overrides.json`：逐原文保護的校訂；原文若改動，重新匯入會停止。
- `reviewed-numeric-equivalences.json`：人工核對的數字寫法差異與原／譯文雜湊。
- `hotdq-import-review.json`及`rot-import-review.json`：完整匯入檢查紀錄。

詳細範圍、來源署名、已修正問題、保留項與重建指令見`reports/zh-tw-tyranny-audit.md`。
