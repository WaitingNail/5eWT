# 5etools zh-TW 翻譯風格指南（草案）

## 語言與版本

- 目標語言為臺灣繁體中文（`zh-TW`）。
- 2014 規則與 2024 規則分開維護；同名規則若機制不同，不共用正文翻譯。
- 2014 的 `Race` 譯為「種族」；2024 的 `Species` 暫譯為「物種」，待術語核准。
- 優先採用本專案已核准的鎖定術語；其次才參考既有繁中社群翻譯。

## 規則與資料結構

- 不改動數值、骰式、DC、距離、範圍、持續時間、充能、動作類型與例外條件。
- 不換算英制單位。原文 `5 feet` 依上下文譯作「5 呎」，資料欄位中的數值維持原樣。
- 保留所有 5etools 標籤與參數，例如 `{@spell ...}`、`{@damage ...}`、`{@condition ...}`。
- JSON 的鍵、陣列順序、來源縮寫、頁碼與跨條目識別值不可翻譯。
- 名稱翻譯與查找鍵分離：英文 canonical name 保留作資料關聯，繁中名稱僅作顯示與搜尋別名。
- `srd`／`srd52` 旗標只能界定條目範圍，正文必須以官方 SRD 5.1／5.2.1 為授權來源校對。

## 文字風格

- 規則句以精確、可掃讀為先，不省略 `must`、`can`、`unless`、`until`、`within`、`up to` 等條件差異。
- 使用全形中文標點；程式碼、骰式、標籤、URL 與縮寫使用原有半形格式。
- 避免中國大陸慣用詞與簡體字；不可為了流暢度改變規則效果。
- 專名首次出現是否附英文，由條目類型決定；列表名稱預設可顯示「繁中（English）」並支援英文搜尋。

## 介面

- 按鈕文字要短且以動作或結果為核心，例如 `Reset` 為「重設」。
- 工具提示可使用完整句，必要時保留快捷鍵與英文縮寫。
- 動態生成的介面文字與靜態 HTML 使用同一組 locale key，不以 DOM 字串取代作最終架構。
- 找不到譯文時回退英文，並在開發模式記錄缺漏 key。

## 授權署名

- SRD 5.1 與 SRD 5.2.1 的繁中衍生內容使用 CC BY 4.0，並在網站與發行包中保留來源、作者、授權連結及修改說明。
- 5etools 程式碼的 MIT 授權與 SRD 內容的 CC BY 4.0 署名分開列示。
- 不將 PHB、DMG、MM 或其他書籍中未由 SRD 釋出的正文納入第一階段翻譯包。

## QA

- 每批檢查 JSON 可解析性、標籤成對、英文識別值未改動、數值與骰式一致。
- 檢查鎖定術語的一對多或多對一衝突。
- 檢查繁簡混用、臺灣字形、全半形空格與標點。
- 以首頁、法術、怪物、職業、物品、規則術語彙編至少六類頁面做視覺回歸測試。
