# 5eWT 全站翻譯專項覆核（2026-10-16）

已完成的全站範圍是**掃描全部已納入翻譯的資料、核對高風險候選並逐句修訂**，不是將全站每句英文重新人工校對。未翻譯的整本書／新戰役英文正文不在本次翻譯範圍。

## 結果

- 掃描 344 份翻譯 JSON、615,942 個字串葉節點（包含標籤、名稱與機械欄位，並非同數量的正文段落）。
- 逐句對照原文修正 132 處；每筆保留原文、舊譯、新譯、來源檔與 JSON 路徑。
- 修正中包含 31 處 master 語境、35 處含掩護程度的段落、8 處含失敗差值門檻的段落；類別可能重疊。
- 將原始資料中 2,587 個具體術語別名標籤納入一致化規則，保留合理的情境式連結顯示文字。
- 逐一驗證 9,058 個具中文狀態標籤；2014／2024 的 15 個狀態名稱使用同一套譯法。
- 保留 16 個 master 正例；並通過既有七本冒險的 113 處語義修訂及 18 個正例回歸檢查。

## 跨版本共用術語

統一的是名稱，各版本的能力效果、持續時間與數值仍依原文保留。例如失能的 2014 與 2024 條文各自保留，不互相覆蓋。

| 英文 | 統一譯法 | 整理的別名 |
| --- | --- | --- |
| deafened | 耳聾 | 失聰 |
| frightened | 恐慌 | 恐懼 |
| grappled | 受擒 | 被擒 |
| incapacitated | 失能 | 無力 |
| prone | 倒地 | 伏地 |
| acrobatics | 特技 | 體操 |
| medicine | 醫藥 | 醫療 |
| perception | 察覺 | 感知 |
| persuasion | 遊說 | 說服 |
| dodge | 閃避 | 迴避 |
| opportunity attack | 藉機攻擊 | 借機攻擊 |
| death saving throw | 死亡豁免檢定 | 死亡豁免 |
| d20 test | d20 檢定 | D20 檢定、D20檢定 |
| hit point dice | 生命骰 | 生命值骰 |
| darkness | 黑暗 | 黑暗術 |


- 狀態名稱：Incapacitated → **失能**；Frightened → **恐慌**；Grappled → **受擒**；Prone → **倒地**。其餘狀態亦經同一規則驗證。
- Perception → **察覺**，與 Wisdom 的**感知**分開；只整理技能標籤及明確標示的技能名稱，不將敘事中的「感知」一律改字。
- 一般照明規則 Darkness → **黑暗**；法術 Darkness → **黑暗術**，依標籤類型分開。
- 附錄、章節等情境式顯示文字不強制改成狀態名稱；不把非機械性的恐懼、無力或伏地敘述一律替換。

## 防止重新匯入後退回舊錯

真正的修正來源為 `translation/zh-TW/reviewed-site-semantics.json`。每次建置會在套用既有翻譯後，核對原文、舊譯／新譯與指定路徑，再套用審定修正及術語規則。遇到來源或指定譯文變更會中止並要求重新覆核；原文 canonical 檔、識別名稱、來源、數值及引用目標集合不作改寫。

修正先按句意決定正確的連結位置，再比較原文與新譯的連結／骰式集合與出現次數。這會攔下「中文看起來合理但連結指到另一個狀態」及意外遺漏規則標籤的問題。

## 範圍與疑義

這次確認並修正了結構化規則術語、條件／效果錯置及選出的高風險段落。自動掃描無法證明未標籤的每一段敘事都沒有語義錯誤，因此不將掃描數量或通過測試當作全站逐句語義認證。
