# HotDQ／RoT 繁體中文整合與校對報告

## 發布狀態

翻譯與全站驗證已完成。先前自動核准審查因公開發布授權不足而阻擋；使用者已於2026-09-12明確回覆「發布」，確認將這兩部模組發布至現有公開網站。本次依此授權更新主分支，由 GitHub Pages 工作流程部署；實際部署結果以該提交的 Actions 紀錄為準。

## 範圍與版本

本次延續 CoS 的網站翻譯層與發布流程，整合《龍後的寶山》（Hoard of the Dragon Queen，HotDQ）及《提亞馬特的崛起》（Rise of Tiamat，RoT）。原文為網站固定使用的 5etools v2.33.3，兩份原文均與固定中文來源所附的英文備份逐位元組一致。

| 項目 | HotDQ | RoT | 合計 |
| --- | ---: | ---: | ---: |
| 章節／附錄區塊 | 15 | 15 | 30 |
| 可顯示文字欄位 | 2,526 | 2,502 | 5,028 |
| 具名標題 | 587 | 563 | 1,150 |
| 朗讀框 | 80 | 48 | 128 |
| 地圖 | 25 | 13 | 38 |
| 渲染標題索引 | 567 | 545 | 1,112 |
| 區域／條目索引 | 681 | 624 | 1,305 |
| 附完整原文的校訂 | 13 | 23 | 36 |

HotDQ 包含戰役概覽、第1至8章、背景、議會評分卡、魔法物品、怪物、概念圖與製作組。RoT 包含戰役概覽、第9至17章及相同種類的附錄；原資料將第11、12章放在同一區塊，保留此結構。

## 譯名與新增詞彙

- 395筆分類／來源映射沿用網站既有名稱，詳見 `site-terminology.csv`。
- 206筆跨書名稱、簡稱及變體彙整於 `terminology.json`，分別標示既有網站譯名、使用者核准名稱與本次暫定名稱。
- 沿用「鐵手套教團」「豎琴手聯盟」「翠綠閒庭」「提亞馬特」「瑞茲米爾」「雷歐辛·厄蘭塔」等既有名稱。
- Neverember 家族姓氏沿用怪物頁瑞納爾·無燼的「無燼」，統一達格魯特在標題、正文與議會表中的姓氏。
- 新訂的地名及角色簡稱屬專案暫定譯名，並非宣稱官方譯名；對照表可供後續統一修訂。
- 章節、房間標題保留英文查找名稱，畫面顯示中英對照。人物、物品與法術引用保留英文目標；複數、所有格及簡稱的顯示文字分別處理。
- `block-classification.csv` 為逐文字欄位的自動區塊分類，供定位朗讀框、規則混合敘述、表格、標題與主持資訊；信心值僅代表分類判斷，不代表翻譯品質評分。

## 主要校訂

- 移除誤混入怪物數量的內部區域ID「1b4」。
- 修正把啵靈蛙寫成蜥蜴人的敘述與同盟關係。
- 修正「至少十天」被寫成「大約十天」。
- 將一處雄鹿追蹤的屬性由誤譯的智力改回感知。
- 將迪德里烏斯的施法屬性改回原文的智力18，並保留感知18。
- 補回提亞馬特每次吞噬五名僕從的數量。
- 召喚儀式改回累積10輪成功進度，不再加入原文沒有的「連續10輪」限制；保留連續兩輪中斷才歸零的條件。
- 區分規則中的輪與回合；保留傷害骰、DC、數值、地圖座標及來源碼。
- 修正雙頭巨人將力量腰帶當作肩帶斜披的敘述；初稿誤寫為仍當腰帶使用。
- 塔拉茲的 Fair 稱號依原文明示的淺色火髮處理，避免誤解為公正。
- 移除一段文字尾端的控制字元、空字元及誤混入的檔名。

## 原始資料疑義與保留項

1. RoT `data/6/entries/7/entries/13/entries/5` 的原文字串把 `area 1` 引用包在重生時間表述中，語法有誤。本次保留原始 `19c` 查找目標，將可顯示文字整理為「1分鐘後，於迷宮的某處出現」。此處引用標記本身仍屬上游資料疑義，可再對原書核對，未改寫英文資料。
2. RoT 古墓手勢敘述的原文神名拼作 `Mystril`。譯為暫定的「蜜絲瑞爾」，並保留一次原文拼法，與原稿錯用的密斯特拉區分；未自行更正英文拼字。
3. 保留圖片內嵌文字、原始地圖、製作人員與出版社名稱。擲骰提示中的英文參數屬原有機械字串，未變更公式。

## 驗證結果

- `npm run test:tyranny`：兩書全部30區塊使用真正的5etools renderer渲染通過。
- 逐文字欄位核對資料引用、區域與跨書連結、骰式與機械參數；原有標題索引及1,305個區域／條目位置保持一致。
- 中文、英文、頁碼搜尋通過，搜尋結果仍使用原英文定位名稱。
- 真正的章節載入函式在HotDQ、RoT、CoS及未翻譯模組之間切換通過；每書獨立快取，缺檔或資料不匹配時回退英文。
- 6筆數字寫法差異經人工核對，附原文／譯文SHA-256及等值理由；沒有未處理的數值、骰式、引用或同來源條目譯名衝突。
- 20筆標籤順序差異是中文語序調整，引用目標及出現次數核對相同。
- `npm run verify`：全站既有翻譯、CoS及本次兩部模組回歸檢查通過。

本次以社群初稿為基礎，完成完整性檢查、跨書術語整理、規則掃描及疑點校訂；並非出版等級的逐句人工審校。所有正文與附錄均已接入網站，後續可依使用者回饋修訂譯名與措辭。
