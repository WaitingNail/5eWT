# 5etools v2.37.0 至 v2.39.1 版本差異

5eWT 本次從 v2.37.0（`8c026b8`）升級至 v2.39.1（`c3d5395`）。以下整理三個上游版本的繁中更新說明。

## v2.38.0（2026-10-14）

- 收錄《Project Lamordia》。
- 冒險與書籍頁匯出 Markdown 時，可一併匯出嵌入的數值資料卡。
- 自製內容的渲染展示頁會依資料結構驗證輸入。
- 改善種族文字轉換器對抗性的辨識。
- 修正文字轉換器與渲染展示頁載入時閃白的問題。
- 修正 JSON 格式化工具誤處理排除目錄的問題。
- 修正錯字並補上資料標籤。

## v2.39.0（2026-10-24）

- 收錄冒險《Shadows of Sithicus》。
- 《Project Lamordia》加入動態地圖檢視器支援與圖標。
- 螢幕夠寬時，以鍵盤移動全站搜尋的選取項目會顯示浮動預覽。
- 法術頁加入「以自願生物為目標」和「以盟友為目標」篩選。
- 修正可選特性頁的「先決條件」無法依所需法術篩選，並改善法術選項的顯示。
- 渲染展示頁的「格式化」按鈕新增鍵盤快捷鍵。
- 自製內容建立器新增「JSON（全部）」，可一次下載目前來源的所有條目類型。原本的下載按鈕依目前來源和編輯模式匯出。
- 修正顯示嵌入的傳奇生物群組時可能發生的崩潰。
- 修正錯字並補上資料標籤。

## v2.39.1（2026-11-02）

- 補上更多《地下城主指南》（2024）的物品圖片。
- 所有清單頁的列印檢視都能下載 Markdown。
- DM 屏風的先攻追蹤器將「匯入設定」移入主設定中的子區塊。
- 修正全站搜尋索引過度移除變音符號，導致搜尋結果出現無法開啟的條目。DM 屏風也使用這套搜尋索引。
- 修正手機切換數值資料卡時，頁面跳回頂端的問題。
- 修正浮動視窗載入物品群組補充敘述時可能發生的崩潰。
- 修正生物屬性值與流程圖區塊的 Markdown 輸出。
- 取得自製內容的視窗新增「已載入」欄位與篩選器。「檢視 JSON」連結移至可展開的預覽內。
- 改善 JSON 轉換時產生的 `@tag` 準確度，並擴大可辨識的範圍，尤其是物品。
- 修正含自製內容時，法術頁列印檢視的排序。
- 修正錯字並補上資料標籤。

## 中文化移植狀態

- 兩版之間共變動 226 個檔案，包含網站程式、建置與測試、角色選項、法術、物品、怪物、冒險、書籍與產生的索引。
- 以 v2.37.0 套妥的中文化補丁合併至 v2.39.1，三方合併有 13 個檔案衝突，涉及怪物頁、法術頁、書籍與冒險閱讀器、共用渲染與清單、角色數值產生器、自製內容介面等。
- 已合併新版程式與 5eWT 中文化，保留法術清單預設環階升冪。已翻譯新法術篩選、四個背景與其補充敘述、十四張怪物數值資料卡及十筆怪物補充敘述、九張新表格，並更新比對到的既有條目譯文。兩部新作品的閱讀頁正文仍為英文。
