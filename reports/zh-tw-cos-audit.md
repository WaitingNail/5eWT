## 名稱與文字處理

- 先比對現有怪物、物品、法術、職業、狀態等翻譯資料；連結名稱依條目類型與來源配對，避免同名不同義的條目互相覆蓋。
- 沿用怪物頁的「施特拉德·馮·扎洛維奇」「伊莉娜·考利安娜」「伊娃夫人」等譯名。
- 章節目錄改由正文標題產生，修正原中文目錄把瓦拉吉寫成瓦拉基等不一致。
- CoS內的藍水旅店／藍水旅館統一成「藍水旅館」；範·裡希騰及人物簡稱沿用既有字形。
- 修正3處遺漏的K84房間編號、鬼牌1／鬼牌2標示、「主持前」誤譯成「開始後」、還魂鬼一年期限敘述、損毀的小男爵標題、部分房間名稱及朗讀文字。
- 數字、骰式、DC、來源、ID、房間座標、圖片路徑與原英文連結目標均保留；沒有套用使用者自家戰役的世界觀改動。
- 章節與房間標題顯示中英對照，中文及英文都能搜尋，舊英文網址仍可定位。

## 驗證

- `npm run verify`：全站既有翻譯、載入器與新CoS檢查通過。
- `npm run test:cos`：全部26個區塊使用真正的5etools renderer渲染通過。
- 1,256個渲染標題的英文索引／順序與原文一致。
- 1,038個區域引用、145個卡牌引用及其他資料引用的查找目標、骰式檢查通過。
- 2,006個區域／條目索引的位置、名稱與原文一致。
- 真正的章節載入函式會載入中文，切換到其他冒險時會清除CoS翻譯狀態；缺少翻譯時回退英文。
- 中文、英文及頁碼搜尋通過；未偵測到未處理的結構、引用、骰式、數值或同來源條目譯名衝突。
- 60筆標籤順序差異是中文語序調整；比對查找參數與出現次數後均相同。143筆數字表示差異經規則與4筆附原／譯文雜湊的人工等值記錄核對。

本次包含自動完整性檢查、規則關鍵字掃描及針對疑點的人工校訂；不代表整份社群初稿已完成出版等級的逐句審校。原圖內嵌的英文、製作人員原名與書目保留原樣。

## 來源與重新產生

原文基準為5etools v2.33.3，commit `e5f3e77b303a92df10487207857200245e71957c`。使用者專案現有翻譯名稱為優先；中文初稿沿用本專案既有來源[tjliqy/5etools-cn](https://github.com/tjliqy/5etools-cn)，固定commit `46b15d04f548c23c526084deae078e3568500349`，轉換方式為OpenCC s2twp、既有術語對齊與本次校訂。中文來源的CC BY-NC-SA 4.0標示沿用本專案既有署名方式，原始冒險內容的權利仍屬其原權利人。

```bash
npm run import:cos -- --source-dir /path/to/pinned-chinese-source
npm run apply
npm run test:cos
npm run verify
```

來源目錄應包含同一固定commit的`data/adventure/adventure-cos.json`、`data-bak/adventure/adventure-cos.json`與`data/adventures.json`。匯入器會先比對原文資料，遇到不相容的結構或過期校訂即停止。
