# Out of the Abyss 繁中整合與校訂

## 範圍

《逃離深淵》（OotA）的17章、4個附錄、後記與製作名單，共23個區塊，已整合至獨立繁中覆蓋層：5,910個可見文字欄位、1,371個標題、117個朗讀框、36個地圖記錄及1,521個區域目標。

英文主資料、識別碼、頁碼、地圖定位與原有網址錨點不變。本次承接主分支 `e0cb9d2`，保留其他工作的變更；只提交至 `codex/campaign-translations`，不更新 `main` 或觸發部署。

## 來源與術語

英文資料為 [5etools v2.33.3 固定版本](https://github.com/5etools-mirror-3/5etools-src/tree/e5f3e77b303a92df10487207857200245e71957c)，中文基稿為 [tjliqy/5etools-cn 固定版本](https://github.com/tjliqy/5etools-cn/tree/46b15d04f548c23c526084deae078e3568500349)。匯入檔記錄兩份來源的 SHA-256，並驗證英文備份與原檔逐位元組相同。保留作者與社群來源署名；翻譯層沿用來源標示的 CC BY-NC-SA 4.0，不另宣稱原始遊戲文字的授權。

依模組翻譯技能的術語、混合內容分類、結構保護與 QA 流程處理。既有網站名稱優先，例如魔索布萊城、布靈登石城、狄摩高根、祖格莫伊、朱庇萊克斯及維茲蘭·迪威爾。本文短稱與全名分開統一；新增名稱屬專案暫定譯名，可依回饋再修訂。

原文的無來源法術引用按本書的2014 PHB版本核對，不混用同名2024條目。語境替換限定在對應英文來源字串，且不更改引用識別碼或已鎖定的全站名稱。

## 主要校訂

- 補回遭遇結算的 `1d4−1`，不把存活卓爾數量誤改成 `1d4`。
- 修正微型、小型及中型生物的通行限制；保留半身與四分之三掩護的區別。
- 將規則中的 disadvantage 明確寫為「劣勢」，而非籠統的「不利」。
- 把阿拉傑塔樓的 Level 還原為樓層，不是法術環級；補回第4、6層遺漏的房間用途。
- 修正法師騎乘蜘蛛形石魔像的關係、迪洛矮人被誤譯成底棲魔魚，以及石化蜥蜴被誤譯成蛇髮女妖。
- 區分惡魔的來源「無底深淵」與其正在活動的「幽暗地域」。
- 補回運送寶石的目的地及交叉引用章號，清除重複章號，明確標示香水與飲料的每瓶單價。
- 保留法術專注、生命骰成本、毒素傷害、負值與追擊恢復條件。
- 統一跨章人物、城市、組織及魔法蘑菇名稱，修正大人物等誤譯。
- 清除混入朗讀框與表格的翻譯指示，以及原文不存在的重複名稱括註。
- 保留開門口令、升降口令與卓爾語的原始拼寫，中文意思仍供主持人閱讀。

共117筆來源保護校訂，另有可重建的語境術語規則。

## 驗證

- `npm run test:oota`：以實際 Renderer 渲染全部23區塊，核對1,353個渲染標題、1,521個區域目標、全部引用識別與骰式，並檢查房間編號及非顯示資料不變。
- 中文／英文全文搜尋及原文頁碼搜尋；七個已翻譯冒險的真實載入流程、獨立快取，以及缺檔、不匹配、未翻譯書籍的英文回退。
- 全欄位英文顯示掃描；保留項為製作人員姓名、NPC等縮寫，以及15個含原文口令或卓爾語的文字欄位。
- 52筆數字表面差異中，50筆可自動分類為等值寫法；另外兩筆為 `forty-eight miles`／`48英里`，已比對方向、距離及鄰近數值並以雙端雜湊綁定。
- 沒有未處理的數值、骰式、引用目標或同來源條目名稱衝突。45筆基稿標籤形狀／順序差異以原文身分重新對齊，並由逐欄位測試檢查結果。
- `npm run verify`：回歸檢查既有冒險及全站覆蓋層，包含其他工作的工具頁、先決條件、怪物、法術、物品、職業、載具、靈能等。

## 限制

本次是社群基稿的全書整合、術語統一、規則與結構掃描及疑點校訂，不是出版等級的逐句人工審校，也不表示全站既有譯名均已重新審定。圖片內嵌文字未重繪。分類信心值只代表欄位分類判斷，不代表翻譯品質。後續仍可依實際使用回饋修訂措辭與新譯名。
