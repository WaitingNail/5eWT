## 驗證方式

1. `npm run apply && npm run verify`：全站既有檢查及七本冒險的結構、數值、引用、渲染、搜尋與載入測試，並包含新語義回歸測試。
2. `npm run test:adventure-semantics-import`：先安裝 `requirements-zh-tw.txt`，使用真正的各戰役匯入器，讓所有已修正欄位從舊譯重新經過覆寫及正規化，確認最後仍等於審定譯文；不修改產出檔。

第二項會檢出「覆寫表已有正譯，但後續別名或網站名稱又將它蓋回舊譯」的問題。這次實際發現並修正了該類名稱回退，另調整三處派系全稱及一處樓梯敘述，使輸出與匯入結果一致。
